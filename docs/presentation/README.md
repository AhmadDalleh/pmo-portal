# Management presentation

`PMO_Portal_Management_Presentation.pptx`: 8 slides (business value, solution overview, architecture, financial management, web intelligence, automation, AI approach, testing and delivery) with speaker notes on every slide. Figures are the seeded baseline (30 September 2026) and match `docs/reconciliation.md`.

Edit it in PowerPoint like any deck. Two places need your own words before the interview: the "To do" line on slide 8 (update when the Power BI report and Access utility exist) and the end of the slide 7 notes (what you personally validated).

Regenerate from code (overwrites manual edits): `pip install python-pptx` then `python docs/presentation/build_deck.py` from the repository root.
